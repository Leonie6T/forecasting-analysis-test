# Forecasting analysis test

A timed test of my working method on a research-institute style data task, run on 17 October 2026.

**Method.** I directed. Claude (Anthropic) wrote and ran the code. I decided the cleaning rules, the unit of analysis, the tests, and what to report. I asked for a review before write-up; that review found an intermediate result that was wrong, and we fixed it. Elapsed: 47 minutes against a two-hour target.

**Data.** Synthetic. 300 forecasters in three groups, 40 binary questions, two waves, with realistic defects injected (duplicates, out-of-range values, missing outcomes). Generated by Claude for this test; no real survey data.

**Brief.** Mean Brier by group with uncertainty; a group test and a within-group experience test; one chart; a 150 to 250 word methods-and-results paragraph.

## Contents

- `data/` raw inputs as supplied
- `scripts/` in run order: `clean.py`, `brier.py`, `tests.py`, `robust.py`, `chart.py`
- `output/cleaning_log.md` every cleaning decision, method selection, robustness check, and open question for the data owner
- `output/results.md` the methods-and-results paragraph
- `output/fig1_brier_by_group.png` the figure
- `output/tests_output.txt`, `output/robustness_output.txt` raw test output

## Reproduce

```
pip install pandas numpy scipy statsmodels matplotlib
cd scripts
python clean.py && python brier.py && python tests.py && python robust.py && python chart.py
```

Scripts expect to run from `scripts/` with data in `../data/` and write to `../output/`.

## What I would do differently with more time

- Decompose Brier into calibration and resolution.
- Fit the mixed model in R (lme4) as a cross-check on the Python fit.
- Test expert accuracy in-domain versus out-of-domain, which needs each expert's domain.
